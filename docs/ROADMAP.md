# 路线图（Roadmap）

> 本路线图反映 GEO-SaaS 未来的发展方向，欢迎社区通过 Issue / Discussion 参与讨论。
> 版本号遵循语义化版本，Beta 阶段接口可能变动。

## 🟢 近期（v1.0.x — 稳定性与体验）

- [ ] **测试补全**：为后端 Service 与前端关键视图补充单元测试 / 组件测试。
- [ ] **端到端 CI**：集成 `smoke_test.py` 到 GitHub Actions，每次 PR 自动冒烟。
- [ ] **文档完善**：补充「API 参考」独立文档与「部署 FAQ」视频/图文。
- [ ] **国际化（i18n）**：前端支持中英双语切换。
- [ ] **可观测性**：后端接入结构化日志与基础 Metrics 端点。

## 🟡 中期（v1.1 — 能力增强）

- [ ] **多 AI 模型接入**：原生支持更多国产大模型（DeepSeek、Kimi、智谱等）。
- [ ] **诊断报告可视化**：ECharts 报告页、PDF 导出、竞品雷达图。
- [ ] **分发调度增强**：可视化定时编排、失败自动重试策略、渠道分组。
- [ ] **多租户（SaaS 化）**：租户隔离、配额、计费埋点（基础版）。
- [ ] **知识库增强**：RAG 检索增强、向量库接入、自动结构化抽取。

## 🔵 长期（v2.0 — 平台化）

- [ ] **开放 API 与 Webhook**：对外提供标准化 OpenAPI，支持第三方集成。
- [ ] **插件市场**：社区可贡献分发渠道适配器与内容模板。
- [ ] **私有化部署套件**：一键离线交付、信创适配（国产数据库/操作系统）。
- [ ] **协作工作流**：团队空间、角色权限细化、操作审计大盘。

## 🤝 社区计划

- 建立 `Good First Issue` 标签，降低新人参与门槛。
- 每季度发布 Release Note 与路线图回顾。
- 优秀贡献者将被列入 README 致谢名单。
