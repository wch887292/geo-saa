# GEO-SaaS 信创数据库适配指南

## 概述

GEO-SaaS 支持多种国产化数据库，通过 MyBatis-Plus 多方言机制和 Maven Profile 实现无缝切换。

## 支持的信创数据库

| 数据库 | 版本 | 方言 | 驱动 | Maven Profile |
|--------|------|------|------|---------------|
| 达梦 DM | 8.0+ | DbType.DM | DmJdbcDriver18 | `dm` |
| 人大金仓 KingbaseES | V8R6+ | DbType.KINGBASE_ES | kingbase8 | `kingbase` |
| 神通数据库 | 7.0+ | DbType.OSCAR | oscar | 需自行添加 |
| 南大通用 GBase | 8s+ | DbType.GBASE | gbasedbt | 需自行添加 |

## 达梦 DM 适配

### 1. 驱动安装

达梦驱动不在 Maven 中央仓库，需手动安装到本地仓库：

```bash
# 从达梦安装目录获取驱动
# Windows: C:\dmdbms\drivers\jdbc\DmJdbcDriver18.jar
# Linux: /opt/dmdbms/drivers/jdbc/DmJdbcDriver18.jar

mvn install:install-file \
  -Dfile=DmJdbcDriver18.jar \
  -DgroupId=com.dameng \
  -DartifactId=DmJdbcDriver18 \
  -Dversion=8.1.3.192 \
  -Dpackaging=jar
```

### 2. 构建项目

```bash
cd geo-saa-backend
mvn clean package -DskipTests -Pdm
```

### 3. 配置数据源

```yaml
spring:
  datasource:
    url: jdbc:dm://localhost:5236/geo_saa?characterEncoding=utf-8
    username: geo_saa
    password: your_password
    driver-class-name: dm.jdbc.driver.DmDriver
```

或使用环境变量：
```env
SPRING_DATASOURCE_URL=jdbc:dm://localhost:5236/geo_saa?characterEncoding=utf-8
SPRING_DATASOURCE_USERNAME=geo_saa
SPRING_DATASOURCE_PASSWORD=your_password
SPRING_DATASOURCE_DRIVER_CLASS_NAME=dm.jdbc.driver.DmDriver
```

### 4. 数据库初始化

达梦 SQL 语法与 MySQL 差异：

| MySQL | 达梦 DM | 说明 |
|-------|---------|------|
| `AUTO_INCREMENT` | `IDENTITY(1,1)` | 自增列 |
| `TINYINT` | `TINYINT` 或 `NUMBER(3)` | 小整数 |
| `DATETIME` | `TIMESTAMP` | 日期时间 |
| `TEXT` | `CLOB` 或 `VARCHAR(8188)` | 大文本 |
| `LONGTEXT` | `CLOB` | 超大文本 |
| `COMMENT 'xxx'` | `COMMENT ON COLUMN ... IS 'xxx'` | 列注释 |
| `ENGINE=InnoDB` | （不需要） | 存储引擎 |
| `DEFAULT CHARSET=utf8mb4` | （建库时指定） | 字符集 |
| `ON UPDATE CURRENT_TIMESTAMP` | 触发器实现 | 自动更新时间 |
| `IF NOT EXISTS` | （不支持，需先判断） | 条件创建 |

达梦适配的初始化脚本请参考 `src/main/resources/db/dameng/` 目录（如已提供）。

### 5. MyBatis-Plus 配置

系统会根据 JDBC URL 自动检测达梦数据库并使用 DM 方言，无需手动配置。

如需显式指定：
```yaml
mybatis-plus:
  configuration:
    db-type: dm
```

## 人大金仓 KingbaseES 适配

### 1. 驱动安装

```bash
# 从金仓安装目录获取驱动
# Linux: /opt/Kingbase/ES/V8R6/KingbaseES/jdbc/kingbase8-8.6.0.jar

mvn install:install-file \
  -Dfile=kingbase8-8.6.0.jar \
  -DgroupId=cn.com.kingbase \
  -DartifactId=kingbase8 \
  -Dversion=8.6.0 \
  -Dpackaging=jar
```

### 2. 构建项目

```bash
cd geo-saa-backend
mvn clean package -DskipTests -Pkingbase
```

### 3. 配置数据源

```yaml
spring:
  datasource:
    url: jdbc:kingbase8://localhost:54321/geo_saa?currentSchema=public
    username: system
    password: your_password
    driver-class-name: com.kingbase8.Driver
```

金仓兼容 PostgreSQL 语法，大部分 MySQL 脚本可直接使用，注意以下差异：

| MySQL | KingbaseES | 说明 |
|-------|------------|------|
| `AUTO_INCREMENT` | `SERIAL` 或 `GENERATED ALWAYS AS IDENTITY` | 自增列 |
| `TINYINT` | `SMALLINT` | 小整数 |
| `DATETIME` | `TIMESTAMP` | 日期时间 |
| `LONGTEXT` | `TEXT` | 大文本 |
| `ENGINE=InnoDB` | （不需要） | 存储引擎 |
| `backtick` 引号 | `"` 双引号 | 标识符引号 |

### 4. 数据库模式

金仓支持 Oracle 模式和 PostgreSQL 模式，建议使用 PostgreSQL 模式：
```sql
-- 创建数据库时指定模式
CREATE DATABASE geo_saa WITH ENCODING 'UTF8' TEMPLATE template0;
-- 连接时指定 currentSchema
```

## 自动数据库检测机制

系统通过 `MybatisPlusConfig.detectDbType()` 方法根据 JDBC URL 自动检测数据库类型：

| URL 包含 | 数据库类型 | 方言 |
|----------|-----------|------|
| `:dm:` | 达梦 DM | DbType.DM |
| `:kingbase:` | 人大金仓 | DbType.KINGBASE_ES |
| `:postgresql:` | PostgreSQL | DbType.POSTGRE_SQL |
| `:oracle:` | Oracle | DbType.ORACLE |
| 其他 | MySQL（默认） | DbType.MYSQL |

## 多租户适配

多租户拦截器 `TenantLineInnerInterceptor` 对所有支持的数据库通用，无需额外适配。

租户表 `tenant` 和业务表的 `tenant_id` 列在所有数据库中通用。

## RAG 向量库适配

向量存储使用 `TEXT` 列存储 JSON 数组格式的 embedding，在所有数据库中通用。

余弦相似度计算在 Java 内存中完成，不依赖数据库特定函数。

## 性能优化建议

### 达梦 DM
```ini
# dm.ini 关键参数
MAX_SESSIONS = 1000
BUFFER = 2000          # 内存缓冲区（MB）
MAX_BUFFER = 4000
CKPT_INTERVAL = 300
WORKER_THREADS = 8
```

### 人大金仓
```conf
# kingbase.conf 关键参数
shared_buffers = 2GB
work_mem = 64MB
maintenance_work_mem = 512MB
effective_cache_size = 6GB
max_connections = 500
```
