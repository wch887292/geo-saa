## 快速部署（Docker）

### 1. 准备环境
```bash
# 安装 Docker（如未安装）
curl -fsSL https://get.docker.com | bash
systemctl enable --now docker

# 安装 Docker Compose 插件
# Docker 20.10+ 已内置 compose 插件，可直接用 docker compose
```

### 2. 获取代码
```bash
cd /opt
git clone <your-repo-url> geo-saa
cd geo-saa
```

### 3. 配置环境变量
```bash
# 复制配置模板
cp .env.example .env

# 编辑配置（必须修改 JWT_SECRET 和数据库密码）
vim .env
```

**必须修改的配置：**
```env
# JWT 密钥（必须修改，可用以下命令生成）
JWT_SECRET=<openssl rand -base64 32 的输出>

# MySQL root 密码
MYSQL_PASSWORD=<your_strong_password>
```

### 4. 一键部署
```bash
# 赋予执行权限
chmod +x deploy.sh

# 默认 MySQL 部署
./deploy.sh

# 或使用 docker compose 直接部署
docker compose -f docker-compose.xinchuang.yml --profile mysql up -d
```

### 5. 验证部署
```bash
# 查看服务状态
./deploy.sh --status

# 查看后端日志
./deploy.sh --logs

# 健康检查
curl http://localhost:8080/actuator/health
```

### 6. 访问系统
- 前端：http://localhost
- 后端 API：http://localhost:8080/api/v1
- 默认管理员：admin / admin123（首次登录后请修改密码）

## 信创数据库部署

### 达梦 DM 部署

#### 1. 准备达梦数据库
```bash
# 方式一：Docker 部署达梦（测试用）
docker run -d --name dameng \
  -p 5236:5236 \
  -e PAGE_SIZE=16 \
  -e UNICODE_FLAG=1 \
  -v /opt/dameng/data:/opt/dmdbms/data \
  registry.cn-hangzhou.aliyuncs.com/dameng/dm8:20230808

# 方式二：物理机部署达梦（生产推荐）
# 参考达梦官方安装文档，安装 DM8 数据库
```

#### 2. 创建数据库和用户
```sql
-- 使用 disql 连接达梦
disql SYSDBA/SYSDBA@localhost:5236

-- 创建表空间
CREATE TABLESPACE geo_saa DATAFILE 'geo_saa.dbf' SIZE 128;

-- 创建用户
CREATE USER geo_saa IDENTIFIED BY "your_password" DEFAULT TABLESPACE geo_saa;

-- 授权
GRANT DBA TO geo_saa;
```

#### 3. 执行数据库脚本
```bash
# 达梦 SQL 语法与 MySQL 略有差异，需使用转换后的脚本
# 参考 docs/信创数据库适配指南.md 获取达梦适配脚本

disql geo_saa/your_password@localhost:5236 `
  `src/main/resources/db/dameng/init_all_dm.sql
```

#### 4. 配置环境变量
```bash
# 编辑 .env，添加达梦配置
SPRING_DATASOURCE_URL=jdbc:dm://localhost:5236/geo_saa
SPRING_DATASOURCE_USERNAME=geo_saa
SPRING_DATASOURCE_PASSWORD=your_password
SPRING_DATASOURCE_DRIVER_CLASS_NAME=dm.jdbc.driver.DmDriver
```

#### 5. 构建并部署
```bash
# 使用达梦 profile 构建
./deploy.sh --db dm

# 或手动构建
cd geo-saa-backend
mvn clean package -DskipTests -Pdm
cd ..
docker compose -f docker-compose.xinchuang.yml --profile dm up -d
```

### 人大金仓 KingbaseES 部署

#### 1. 准备金仓数据库
```bash
# Docker 部署金仓（测试用）
docker run -d --name kingbase \
  -p 54321:54321 \
  -e DB_USER=system \
  -e DB_PASSWORD=your_password \
  -e DB_NAME=geo_saa \
  -v /opt/kingbase/data:/home/kingbase/data \
  registry.cn-hangzhou.aliyuncs.com/kingbase/kingbasees:v8r6
```

#### 2. 配置环境变量
```bash
# 编辑 .env
SPRING_DATASOURCE_URL=jdbc:kingbase8://localhost:54321/geo_saa
SPRING_DATASOURCE_USERNAME=system
SPRING_DATASOURCE_PASSWORD=your_password
SPRING_DATASOURCE_DRIVER_CLASS_NAME=com.kingbase8.Driver
```

#### 3. 构建并部署
```bash
./deploy.sh --db kingbase
```

## ARM 架构部署（飞腾/鲲鹏）

### 1. 确认架构
```bash
uname -m
# 输出 aarch64 表示 ARM64 架构
```

### 2. 安装 ARM 版 Docker
```bash
# 麒麟/统信系统
yum install -y docker
systemctl enable --now docker
```

### 3. 多架构构建
```bash
# 使用 buildx 构建 ARM64 镜像
docker buildx create --name multiarch --use
docker buildx build \
  --platform linux/arm64 \
  -t geo-saa-backend:arm64 \
  -f geo-saa-backend/docker/Dockerfile \
  geo-saa-backend/ \
  --load

# 前端同样构建 ARM64 镜像
docker buildx build \
  --platform linux/arm64 \
  -t geo-saa-frontend:arm64 \
  geo-saa-frontend/ \
  --load
```

### 4. 使用 ARM64 镜像部署
```bash
# 修改 docker-compose.xinchuang.yml 中的镜像标签
# backend: image: geo-saa-backend:arm64
# frontend: image: geo-saa-frontend:arm64

docker compose -f docker-compose.xinchuang.yml --profile mysql up -d
```

### 5. JVM ARM 优化
```env
# 在 .env 中添加 ARM 优化参数
JAVA_OPTS=-XX:+UseContainerSupport -XX:MaxRAMPercentage=75.0 \
  -XX:+UseG1GC -XX:MaxGCPauseMillis=200 \
  -Dfile.encoding=UTF-8
```

## 裸机部署（无 Docker）

### 1. 安装 JDK 17
```bash
# 麒麟/统信
yum install -y java-17-openjdk

# 或使用毕昇 JDK（ARM 推荐）
# 下载地址：https://www.hikunpeng.com/developer/devkit/compiler/jdk
```

### 2. 安装 MySQL/Redis
```bash
yum install -y mysql-server redis
systemctl enable --now mysqld redis
```

### 3. 初始化数据库
```bash
mysql -u root -p < geo-saa-backend/src/main/resources/db/init.sql
mysql -u root -p geo_saa < geo-saa-backend/src/main/resources/db/V2__multi_tenant.sql
mysql -u root -p geo_saa < geo-saa-backend/src/main/resources/db/V3__rag_vector.sql
mysql -u root -p geo_saa < geo-saa-backend/src/main/resources/db/V4__open_api_webhook.sql
```

### 4. 构建后端
```bash
cd geo-saa-backend
mvn clean package -DskipTests
cp target/geo-saa-backend.jar /opt/geo-saa/
```

### 5. 配置 systemd 服务
```bash
cat > /etc/systemd/system/geo-saa-backend.service << 'EOF'
[Unit]
Description=GEO-SaaS Backend Service
After=network.target mysqld.service redis.service

[Service]
Type=simple
User=geosaa
WorkingDirectory=/opt/geo-saa
EnvironmentFile=/opt/geo-saa/.env
ExecStart=/usr/bin/java -jar /opt/geo-saa/geo-saa-backend.jar --spring.profiles.active=prod
Restart=on-failure
RestartSec=10
LimitNOFILE=65536

[Install]
WantedBy=multi-user.target
EOF

systemctl daemon-reload
systemctl enable --now geo-saa-backend
```

## 配置说明

### 核心配置项

| 配置项 | 环境变量 | 默认值 | 说明 |
|--------|----------|--------|------|
| 服务端口 | SERVER_PORT | 8080 | 后端服务端口 |
| 数据库 URL | SPRING_DATASOURCE_URL | mysql://localhost:3306/geo_saa | JDBC 连接地址 |
| 数据库用户 | SPRING_DATASOURCE_USERNAME | root | 数据库用户名 |
| 数据库密码 | SPRING_DATASOURCE_PASSWORD | root | 数据库密码 |
| Redis 主机 | REDIS_HOST | localhost | Redis 地址 |
| Redis 密码 | REDIS_PASSWORD | （空） | Redis 密码 |
| JWT 密钥 | JWT_SECRET | （必填） | JWT 签名密钥 |
| CORS 来源 | CORS_ALLOWED_ORIGINS | http://localhost | 允许的前端域名 |
| AI 模拟模式 | AI_SIMULATION_ENABLED | false | 无 API Key 时是否使用模拟数据 |
| MQ 启用 | RABBITMQ_ENABLED | false | 是否启用 RabbitMQ |

### 多租户配置
- 默认租户 ID：1
- 超级管理员角色：SUPER_ADMIN（跳过租户过滤）
- 租户管理 API：`/api/v1/system/tenant`

### RAG 配置
- Embedding 模型：text-embedding-3-small（1536 维）
- 分块大小：500 字符，重叠 50 字符
- 默认 Top-K：5，最小相似度：0.3

## 数据库迁移

### 版本顺序
```
init.sql (V1 基础表)
  ↓
V2__multi_tenant.sql (多租户)
  ↓
V3__rag_vector.sql (RAG 向量库)
  ↓
V4__open_api_webhook.sql (开放 API/Webhook)
```

### 升级操作
```bash
# 从 V1 升级到 V2
mysql -u root -p geo_saa < V2__multi_tenant.sql

# 从 V2 升级到 V3
mysql -u root -p geo_saa < V3__rag_vector.sql

# 从 V3 升级到 V4
mysql -u root -p geo_saa < V4__open_api_webhook.sql
```

### 备份与回滚
```bash
# 备份
mysqldump -u root -p geo_saa > backup_$(date +%Y%m%d).sql

# 回滚
mysql -u root -p geo_saa < backup_20240101.sql
```

## 运维管理

### 常用命令
```bash
# 启动/停止/重启
./deploy.sh --restart
./deploy.sh --stop

# 查看日志
```

```bash
# 健康检查
curl http://localhost:8080/actuator/health

# Prometheus 指标
curl http://localhost:8080/actuator/prometheus

# 业务指标
# geo_http_requests_total - HTTP 请求总数
```

## 常见问题

### Q1: 启动报错 "JWT_SECRET is required"
A: 编辑 `.env` 文件，设置 `JWT_SECRET` 为随机字符串：
```bash
openssl rand -base64 32
```

### Q2: 数据库连接失败
A: 检查：
1. 数据库服务是否启动：`docker ps | grep mysql`
2. 数据库密码是否正确：检查 `.env` 中的 `MYSQL_PASSWORD`
3. 网络是否连通：`docker exec -it geo-saa-backend ping mysql`

### Q3: 达梦数据库部署后中文乱码
A: 确保达梦数据库创建时设置了 `UNICODE_FLAG=1`（UTF-8），并在 JDBC URL 中添加字符集参数：
```
jdbc:dm://localhost:5236/geo_saa?characterEncoding=utf-8
```

### Q4: ARM 架构下 Docker 镜像无法启动
A: 使用 `--platform linux/arm64` 重新构建镜像，或使用预构建的 ARM64 镜像。

### Q5: 如何修改管理员密码
A: 登录后通过 API 修改：
```bash
curl -X POST http://localhost:8080/api/v1/auth/change-password \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{"oldPassword":"admin123","newPassword":"new_password"}'
```

### Q6: 如何备份数据
A:
```bash
# MySQL 备份
docker exec geo-saa-mysql mysqldump -u root -p<password> geo_saa > backup.sql

# Redis 备份
docker exec geo-saa-redis redis-cli BGSAVE
docker cp geo-saa-redis:/data/dump.rdb ./
```
